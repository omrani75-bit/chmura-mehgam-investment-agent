# Chmura Co – Mehgam Manufacturing Investment AI Agent

**Interactive Decision Support Tool** built for Greenwich Strategy Ltd clients.

This professional Streamlit application provides a complete investment appraisal for the proposed manufacturing project in Mehgam, including:

- Full cash flow modelling (MP and USD)
- Black-Scholes real option valuation (Bulud Co put option)
- Sensitivity analysis
- Monte Carlo simulation
- Natural language AI assistant ("Ask the AI Agent")

## Live Demo

[https://chmura-mehgam-investment-agent.streamlit.app](https://chmura-mehgam-investment-agent.streamlit.app)

## Key Features

- **Live What-If Analysis**: Adjust assumptions in real time
- **Strategic Recommendation Engine**: Clear go/no-go decision with justification
- **Professional PDF Report Generation**: One-click branded executive summary
- **Risk Analysis**: Monte Carlo simulation with VaR
- **Conversational AI Assistant**: Ask questions in plain English
